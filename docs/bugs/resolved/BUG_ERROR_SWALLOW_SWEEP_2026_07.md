**Status**: Resolved (2026-07-19). Owner ruling: error swallows get fixed — and every enumerated entry below now carries its resolution. High-severity CRDT surfaces landed red-first with pins; the mechanical guard-tails landed with the conventions section's idioms; two entries resolved by owner-ruled deletion (`antiJoinOnSymbols` dead pair, the C8 superseded temporal API); the prefetch entry produced the session's ruling that best-effort never licenses swallowing and annotations are never an error channel. Fixed in the same session, before this sweep: `thetaJoinPair` (eval-error continue + both deferred iterator errors + Close errors), `mergeJoinIterator` (deferred scan error tail).

Three shapes:
- **A** — an eval/decode error inside an iteration loop is treated as skip (`continue`), neither recorded nor returned.
- **B** — a hand-rolled `for iter.Next()` loop never consults `iter.Error()` afterwards: a failed scan is presented as a completed (possibly empty) result.
- **close-only** — `.Error()` is consulted but the `Close()` return is discarded.

## Conventions used by the 2026-07-19 fixes

- Functions with an error return propagate directly; relation-returning functions without one carry the failure as the result's deferred error (`result.err`) — both in-band.
- First error wins, Close included: `scanErr := iter.Error(); if closeErr := iter.Close(); scanErr == nil { scanErr = closeErr }`. A bare or `_ =` Close appears only where a primary error is already being returned on that path.
- **Owner ruling (2026-07-19)**: an error from the store fails the operation, best-effort or not — prefetch being an optimization does not make store failures ignorable. Annotations are observability of healthy execution, never an error channel; routing an error into a collector event is smuggling, not handling.
- Pins: `scan_error_propagation_test.go` (storage: unique resolve ×2, validateCandidate, PrefetchEntities — deferred-error and decode shapes each) and `iterator_error_boundary_test.go` (executor: crossProduct, Select, PrependedRelation.Materialize, BufferedIterator.Clone, extractEntityIDs). The remaining mechanical guard-tails ride the full suite.
